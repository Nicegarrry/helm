# Helm learnings: QOS, eve agents and services they share: live turns, keys and quotas.

- 2026-11-01: Vercel sensitive env vars pull as empty strings, so QOS's qWork agent key couldn't be read for a live subscribe -> rotate the agent key as its owner (`npx convex run --prod agents:rotateKey --identity '{"subject":…,"email":…}'`), set it on Vercel and redeploy, then keep a 600-mode copy in `~/.config/<app>/`
- 2026-11-04: four live dry runs of a wiki-hygiene job called qwiki `lint` per folder, whose body checks read up to 300 pages each from GitHub; qwiki's GitHub token hit its rate limit (health 403) and every agent's wiki reads failed for the hour -> before a live run against a shared service, count the upstream calls it fans out to (and the service's own quota), use index-only paths, and run once, not in a loop
- 2026-11-06: a kit tool with a zod discriminatedUnion input passed typecheck, tests and `eve build`, then the model API rejected every qos turn (`input_schema.type: Field required`) for 3 min after merge -> tool input schemas must be a top-level `z.object`; after merging to any live agent run one real turn (`eve remote connect -u <url> --print "..."`) straight away, and know the previous deployment URL so `vercel rollback` is one command (it stops auto-assign, so the fix needs `vercel promote`)
- 2026-11-07: eve self-mod inherited the parent model as `${provider}/${modelId}`, so every gateway() agent got `gateway/anthropic/...` and model_not_found; my pre-merge probes used a CLI principal the mount correctly denied, so the subagent never ran until the real nightly -> before calling a gated path proven, run it once as an allowed principal in a real deploy (a founder DM counts), and treat "denied correctly" as proof of the gate only, not of what sits behind it
- 2026-11-07: "fixed" a mount model with a gateway-valid id that eve's catalog lacked, and smoke-tested as a principal the mount denies, so PA failed every owner turn for 32 min while the smoke said ok -> a smoke turn proves nothing for a path that principal cannot reach; check ids against .eve/cache/model-catalog.json, and get one authorized turn right after deploy before reporting fixed
